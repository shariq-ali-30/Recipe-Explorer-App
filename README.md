# Recipe Explorer App

## About The Project

Recipe Explorer is an interactive recipe browsing application built using HTML, CSS, and JavaScript.

The purpose of this project was to practice working with APIs, asynchronous JavaScript, DOM manipulation, search functionality, and dynamic content rendering by creating an application where users can explore recipes, view detailed information, and search recipes by name or cuisine.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DummyJSON API
- Fetch API
- Phosphor Icons
- Google Fonts (Inter)

## Features

- Fetch recipes dynamically from DummyJSON API
- Display recipes in a searchable sidebar
- Search recipes by name or cuisine
- Select a recipe to view its complete details
- Display recipe image, rating, cuisine, difficulty, and servings
- Show preparation time and cooking time
- Display calories per serving
- Show meal type and recipe tags
- Display complete ingredients list
- Display step-by-step cooking instructions
- Active recipe selection state
- Empty state when no recipe is selected
- No-results state for unsuccessful searches
- Responsive two-column layout
- Responsive design for mobile, tablet, and desktop devices
- Clean and modern user interface
- Dynamic content rendering using JavaScript
